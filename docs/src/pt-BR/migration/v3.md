## Mudanças no escopo de suporte

- Node.js:

  A V3 suporta apenas a versão LTS mais recente do Node.

  As versões LTS atuais são Node.js 18 e Node.js 20, o que significa que removemos o suporte ao Node 14 e ao Node 16.

- Navegador:

  A V3 suporta apenas navegadores modernos, alinhando-se ao [intervalo padrão de suporte a navegadores](https://vitejs.dev/guide/build.html#browser-compatibility) do Vite
  - Chrome >=87
  - Firefox >=78
  - Safari >=14
  - Edge >=88

## Remoção de recursos

- Agora, ao obter o caminho vinculado a um elemento de contador, o `id` não é mais lido. Você deve usar `data-path`.
- Os pacotes legados foram removidos.

## Atualização das variáveis CSS

O `bgcolor` das variáveis CSS foi alterado para `bg-color`:

```diff
---waline-bgcolor: #fff;
+--waline-bg-color: #fff;
---waline-bgcolor-light: #f8f8f8;
+--waline-bg-color-light: #f8f8f8;
---waline-bgcolor-hover: #f0f0f0;
+--waline-bg-color-hover: #f0f0f0;
---waline-disable-bgcolor: #f8f8f8;
+--waline-disable-bg-color: #f8f8f8;
---waline-code-bgcolor: #282c34;
+--waline-code-bg-color: #282c34;
---waline-info-bgcolor: #f8f8f8;
+--waline-info-bg-color: #f8f8f8;
```
