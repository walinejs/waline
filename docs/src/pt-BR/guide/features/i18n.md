O Waline já vem com suporte a vários idiomas, e você também pode personalizar a configuração de idioma do Waline.

<!-- more -->

## Cliente

### Definir idioma

Você pode definir o idioma usado pelo Waline com a opção `lang`. Os idiomas suportados são:

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

Exemplo:

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Se você quiser ajudar o Waline a oferecer suporte a mais idiomas, fique à vontade para enviar um PR para [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n).

:::

### Personalizar

Você pode personalizar o idioma com a opção `locale` ou definir alguns campos para substituir os textos existentes da interface.

Para mais detalhes, veja [Livro de receitas → Personalizar idioma](../../cookbook/customize/locale.md).

## Servidor

As informações retornadas pela interface do servidor alternarão o idioma dinamicamente com base no parâmetro lang informado pelo cliente.

## Personalizar

Você pode personalizar o conteúdo do idioma correspondente com a opção `locales`; veja [Livro de receitas → Personalizar idioma](../../cookbook/customize/locale.md) para mais detalhes.
