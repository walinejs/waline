Waline supporta più lingue in modo nativo e puoi anche personalizzare la configurazione della lingua di Waline.

<!-- more -->

## Client

### Impostare la lingua

Puoi impostare la lingua usata da Waline tramite l'opzione `lang`. Le lingue supportate sono:

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

Ad esempio:

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Se vuoi aiutarci ad aggiungere altre lingue a Waline, ti invitiamo a inviare una PR a [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n).

:::

### Personalizzare

Puoi personalizzare la lingua tramite l'opzione `locale`, oppure impostare alcuni campi per sovrascrivere i testi già presenti nell'interfaccia.

Per i dettagli vedi [Cookbook → Personalizzare la lingua](../../cookbook/customize/locale.md).

## Server

Le informazioni restituite dalle interfacce del server cambiano lingua in modo dinamico in base al parametro lang inviato dal client.

## Personalizzare

Puoi personalizzare i contenuti della lingua corrispondente tramite l'opzione `locales`; per i dettagli vedi [Cookbook → Personalizzare la lingua](../../cookbook/customize/locale.md).
