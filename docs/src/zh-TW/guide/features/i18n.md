Waline 內建多種語言支援，你也可以自訂 Waline 的語言設定。

<!-- more -->

## 客戶端

### 設定語言

你可以透過 `lang` 選項設定 Waline 所使用的語言，支援的語言有:

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

例如:

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

如果你想要協助 Waline 新增更多語言支援，我們歡迎你發送 PR 到 [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n)。

:::

### 自訂語言

你可以透過 `locale` 選項自訂語言，或設定其中幾項來覆蓋現有的 UI 文字，詳見 [Cookbook → 自訂語言支援](../../cookbook/customize/locale.md)

## 伺服器

伺服器介面傳回的資訊，會根據客戶端傳入的 lang 參數動態切換語言。

### 自訂語言

你可以透過 `locales` 選項自訂對應語言的內容，詳見 [Cookbook → 自訂語言支援](../../cookbook/customize/locale.md)
