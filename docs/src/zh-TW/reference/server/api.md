## 留言 API

### 留言列表

取得某篇文章對應的留言列表

```http
GET /api/comment
```

**參數**：

| 欄位     | 型別   | 描述                                                                                                             |
| -------- | ------ | ---------------------------------------------------------------------------------------------------------------- |
| path     | string | 取得對應文章識別碼的留言列表                                                                                     |
| page     | number | 留言列表的頁數                                                                                                   |
| pageSize | number | 每頁留言列表的筆數                                                                                               |
| sortBy   | string | 留言排序方式，預設依時間倒序（insertedAt_desc），也可以選擇依時間正序（insertedAt_asc）、依熱度倒序（like_desc） |

`like_desc` 以整串討論的**主留言讚數＋公開回覆數＋公開回覆讚數**排序，包含各層回覆。待審、垃圾留言及其他頁面的回覆不計入熱度，即使目前使用者有權限看到這些留言也一樣。置頂留言仍排最前面；同分時依留言 ID 倒序排列。回傳的 `like` 仍代表該則留言本身的讚數。

熱度在查詢時、分頁前計算，既有留言及後續按讚、審核、刪除、資料匯入都不需要額外回填。SQL、MongoDB 與 CloudBase 在資料庫內完成排序；GitHub 儲存原本就會將 CSV 載入記憶體。舊版 LeanCloud 後端則讀取該頁所有留言的排序欄位，在記憶體排序後才讀取當頁留言內容，因此資源成本會隨留言數增加。

既有 SQL 資料庫建議新增 `(rid, url, status)` 索引，避免每個主留言都掃描整張表；新部署的 SQL 範本已包含索引。例如（請依部署調整資料表名稱與前綴）：

```sql
CREATE INDEX idx_comment_rid_url_status ON wl_Comment (rid, url, status);
```

MongoDB／CloudBase 請建立相同欄位順序的複合索引。

### 留言數

取得某篇文章對應的留言總數

```http
GET /api/comment?type=count
```

**參數**：

| 欄位 | 型別   | 描述                                                 |
| ---- | ------ | ---------------------------------------------------- |
| url  | string | 取得對應文章識別碼的留言列表，若為空會傳回全站留言數 |

### 最近留言

取得目前網站的最近留言

```http
GET /api/comment?type=recent
```

**參數**：

| 欄位  | 型別   | 描述               |
| ----- | ------ | ------------------ |
| count | number | 傳回最新留言的筆數 |

### 發表留言

發表一則留言

```http
POST /api/comment
```

**參數**：

| 欄位    | 型別   | 描述                        |
| ------- | ------ | --------------------------- |
| comment | string | 留言內容                    |
| link    | string | 使用者輸入的網站            |
| mail    | string | 使用者輸入的電子郵件        |
| nick    | string | 使用者輸入的暱稱            |
| pid     | string | 該則留言回覆的留言 objectId |
| rid     | string | 該則留言的根留言 objectId   |
| ua      | string | 使用者的 user agent         |
| url     | string | 留言的文章識別碼            |
| at      | string | 該則留言回覆的留言作者暱稱  |

## 閱讀統計 API

### 取得閱讀統計數

取得某篇文章或多篇文章對應的閱讀數

```http
GET /api/article
```

**參數**：

| 欄位 | 型別   | 描述                                 |
| ---- | ------ | ------------------------------------ |
| path | string | 對應文章識別碼，多個識別碼以逗號串接 |

### 更新閱讀統計數

更新某篇文章的閱讀數

```http
POST /api/article
```

**參數**：

| 欄位 | 型別   | 描述           |
| ---- | ------ | -------------- |
| path | string | 對應文章識別碼 |
