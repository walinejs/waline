::: info Waline

一款從 [Valine](https://valine.js.org) 衍生的帶後端留言系統。可以將 Waline 等價成 With backend Valine.

:::

<!-- more -->

## 特色

- 快速
- 真·安全
- Markdown 語法支援
- 輕量易用
- 免費部署
- 多種部署方式與儲存服務支援，每列選擇一項多達 243 種部署方式任君選擇

|                                                 | Waline                                                          |                                    |
| ----------------------------------------------- | --------------------------------------------------------------- | ---------------------------------- |
| **客戶端腳本**                                  | **伺服器部署**                                                  | **資料儲存**                       |
| [@waline/client](https://waline.js.org)         | [Vercel](https://vercel.com)                                    | [MongoDB](https://mongodb.com)     |
| [MiniValine](https://minivaline.js.org/)        | [CloudBase](https://cloudbase.net/)                             | MySQL                              |
| [sodesu](https://github.com/BeiyanYunyi/sodesu) | [百度雲 CFC](https://console.bce.baidu.com/cfc/#/cfc/functions) | SQLite                             |
|                                                 | [阿里雲 FC](https://fc.console.aliyun.com/)                     | PostgreSQL                         |
|                                                 | [阿里雲 計算巢](https://computenest.console.aliyun.com)         | [TiDB](https://tidbcloud.com/)     |
|                                                 | [Railway](https://railway.app)                                  | [CloudBase](https://cloudbase.net) |
|                                                 | [Render](https://render.com)                                    | [GitHub](https://github.com)       |
|                                                 | [Zeabur](https://zeabur.com)                                    |                                    |
|                                                 | [Netlify](https://netlify.com)                                  |                                    |
|                                                 | Docker                                                          |                                    |
|                                                 | 獨立部署                                                        |                                    |
