## 支援範圍變動

- Node.js:

  V3 僅支援最新的 LTS Node 版本。

  目前的 LTS 版本為 Node.js 18 與 Node.js 20，這意味著我們移除了 Node.14, Node 16 的支援。

- 瀏覽器:

  V3 僅支援現代瀏覽器，與 Vite 的 [預設瀏覽器支援範圍](https://cn.vitejs.dev/guide/build.html#browser-compatibility) 對齊
  - Chrome >=87
  - Firefox >=78
  - Safari >=14
  - Edge >=88

## 功能移除

- 現在，讀取計數器元素對應的路徑時，不會再讀取 `id`，你應該使用 `data-path`。
- Legacy 套件已被移除。

## CSS 變數修改

CSS 變數中的 `bgcolor` 替換為 `bg-color`:

```diff
---waline-bgcolor: #fff;
+--waline-bg-color: #fff;
---waline-bgcolor-light: #f8f8f8;
+--waline-bg-color-light: #f8f8f8;
---waline-bgcolor-hover: #f0f0f0;
+--waline-bg-color-hover: #f0f0f0;
---waline-disable-bgcolor: #f8f8f8;
+--waline-disable-bg-color: #f8f8f8;
---waline-code-bgcolor: #282c34;
+--waline-code-bg-color: #282c34;
---waline-info-bgcolor: #f8f8f8;
+--waline-info-bg-color: #f8f8f8;
```
