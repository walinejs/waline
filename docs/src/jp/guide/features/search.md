`@waline/client` では、絵文字検索サービスを追加したり、この機能をカスタマイズしたりできます。

デフォルトでは、`@waline/client` は [Giphy](https://giphy.com/) 経由のミーム検索サービスを提供します。これにより、画像を検索してコメントに追加できます。

<!-- more -->

## 無効化

デフォルトの画像検索サービスが不要な場合は、`search` オプションを `false` に設定して無効化できます。

```js
Waline.init({
  el: '#waline',
  // ...
  search: false,
});
```

## カスタマイズ

search オプションを通じて画像検索サービスをカスタマイズできます。

各操作では、検索結果として画像情報を含む配列を返してください。各項目は次のプロパティを持つオブジェクトです：

- `src`: 画像のリンクアドレス
- `title`: 画像のタイトルと alt テキスト（任意）
- `preview`: 結果一覧で使用する画像のサムネイル（任意）

このオプションは 3 つの関数を受け取ります。いずれも Promise を返す必要があり、その結果が上記の検索結果の配列になります。

- `search`: 検索操作。検索語は関数の第 1 引数として渡されます。
- `default`: デフォルトで表示する画像の一覧（任意）
- `more`: 画像が下端までスクロールされたときに呼び出される関数。検索語と現在の件数が最初の 2 つの引数として渡されます（任意）。

カスタム検索のチュートリアルは [クックブック → カスタム絵文字検索](../../cookbook/customize/search.md) を参照してください。
