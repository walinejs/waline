Waline は多言語対応を標準で備えており、Waline のロケール設定をカスタマイズすることもできます。

<!-- more -->

## クライアント

### 言語を設定する

`lang` オプションで Waline が使用する言語を設定できます。対応している言語は次のとおりです：

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

例：

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Waline の言語サポート拡充にご協力いただける場合は、[client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n) への PR を歓迎します。

:::

### カスタマイズ

`locale` オプションで言語をカスタマイズできます。一部のフィールドを設定して、既存の UI テキストを上書きすることもできます。

詳しくは [クックブック → ロケールのカスタマイズ](../../cookbook/customize/locale.md) を参照してください。

## サーバー

サーバーインターフェースが返す情報は、クライアントから入力された lang パラメータに基づいて言語を動的に切り替えます。

## カスタマイズ

`locales` オプションで該当する言語のコンテンツをカスタマイズできます。詳しくは [クックブック → ロケールのカスタマイズ](../../cookbook/customize/locale.md) を参照してください。
