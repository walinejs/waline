## APIの変更

Walineのデフォルトエクスポートを削除し、代わりに以下のエクスポートを提供します：

- `init`: 以前の`Waline`と同じ動作
- `version`: バージョン番号
- `commentCount`: コメント数の更新
- `pageviewCount`: 訪問数の更新
- `RecentComments`: 最近のコメント

Walineのデフォルトエクスポートを`init`という名前付きエクスポートに変更し、WalineをSSRフレンドリーにするため、V2ではCSSを別途エクスポートします。

ほとんどの場合、必要な変更は次のとおりです：

```diff
- <script src='//cdn.jsdelivr.net/npm/@waline/client'></script>
+ <script src='//unpkg.com/@waline/client@v2/dist/waline.js'></script>
+ <link href='//unpkg.com/@waline/client@v2/dist/waline.css' rel='stylesheet' />

  <script>
-  Waline({
+  Waline.init({
    el: '#waline',
    serverURL: 'YOUR SERVER URL'
  });
  </script>
```

## 追加されたオプション

- `comment`オプションは、CSSセレクターとして文字列を設定できます。
- `pageview`オプションは、CSSセレクターとして文字列を設定できます。

## 名前が変更されたオプション

- `uploadImage`は`imageUploader`に名前が変更されました

- `highlight`は`highlighter`に名前が変更されました

- `previewMath`は`texRenderer`に名前が変更されました

- `visitor`は`pageview`に名前が変更されました

## 削除されたオプション

以下のオプションはV1で長らく非推奨APIとしてマークされていたもので、V2で削除されました。

- `langMode`: `locale`を使用してください
- `placeholder`: `locale.placeholder`を使用してください
- `emojiCDN`: `emoji`を使用してください
- `emojiMaps`: `emoji`を使用してください
- `requiredFields`: `requiredMeta`を使用してください
- `avatar`: サーバー変数`AVATAR_PROXY`を使用してください
- `avatarCDN`: サーバー変数`AVATAR_PROXY`を使用してください
- `avatarForce`: デフォルトで更新されます
- `anonymous`: `login`を使用してください
- `mathTagSupport`: `texRenderer`を使用してください
- `copyRight`: `copyright`を使用してください

## その他の変更

### インスタンス

`Waline.init`は、必須プロパティである`el`と`serverURL`が無効な場合に、理由付きのエラーインスタンスを返すのではなく、エラーをスローするようになりました。

ユーザーが無効なオプションを設定した場合の互換性を高めるため、`try { ... } catch (err) { ... }`ブロックでエラーをキャッチできます。

### 更新動作の変更

- Walineは`el`オプションを除くすべてのオプションを、`Instance.update`で更新できるようになりました。
- `path`パラメータは`update()`でリセットされます。つまり、`update()`時に`path`オプションを渡さない限り、`window.location.pathname`になります。

### コメントとページビューのセレクターの変更

Valineのセレクターとの互換性は現在削除されています。

- コメントのセレクターはデフォルトで`'.waline-comment-count'`です
- ページビューのセレクターはデフォルトで`'.waline-pageview-count'`です

セレクターで現在のページとは異なる値を取得する必要がある場合は、`data-path`属性の使用を強くお勧めします。

互換性のため、以前の`id`属性のサポートは残していますが、この互換性はV3で削除されます。

### CSSクラスの変更

すべてのCSSクラスが`v`から`wl-`に変更されました。
