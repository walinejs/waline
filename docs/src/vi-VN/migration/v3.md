## Thay đổi phạm vi hỗ trợ

- Node.js:

  V3 chỉ hỗ trợ phiên bản Node LTS mới nhất.

  Các phiên bản LTS hiện tại là Node.js 18 và Node.js 20, nghĩa là chúng tôi đã bỏ hỗ trợ Node.14 và Node 16.

- Trình duyệt:

  V3 chỉ hỗ trợ các trình duyệt hiện đại, tương ứng với [Phạm vi hỗ trợ trình duyệt mặc định](https://vitejs.dev/guide/build.html#browser-compatibility) của Vite
  - Chrome >=87
  - Firefox >=78
  - Safari >=14
  - Edge >=88

## Tính năng bị loại bỏ

- Hiện nay, khi lấy path gắn với một phần tử counter, `id` không còn được đọc nữa. Bạn nên dùng `data-path`.
- Các gói kế thừa đã bị loại bỏ.

## Cập nhật biến CSS

`bgcolor` trong các biến CSS được đổi thành `bg-color`:

```diff
---waline-bgcolor: #fff;
+--waline-bg-color: #fff;
---waline-bgcolor-light: #f8f8f8;
+--waline-bg-color-light: #f8f8f8;
---waline-bgcolor-hover: #f0f0f0;
+--waline-bg-color-hover: #f0f0f0;
---waline-disable-bgcolor: #f8f8f8;
+--waline-disable-bg-color: #f8f8f8;
---waline-code-bgcolor: #282c34;
+--waline-code-bg-color: #282c34;
---waline-info-bgcolor: #f8f8f8;
+--waline-info-bg-color: #f8f8f8;
```
