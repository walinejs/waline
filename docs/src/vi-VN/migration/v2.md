## Thay đổi API

Chúng tôi đã bỏ export mặc định của Waline và thay bằng các export sau:

- `init`: hoạt động như `Waline` trước đây
- `version`: số phiên bản
- `commentCount`: cập nhật số lượng bình luận
- `pageviewCount`: cập nhật số lượt truy cập
- `RecentComments`: bình luận gần đây

Chúng tôi đổi export mặc định của Waline thành named export `init`, và để Waline thân thiện với SSR, V2 xuất CSS riêng.

Trong hầu hết trường hợp, điều này chỉ có nghĩa là những thay đổi sau:

```diff
- <script src='//cdn.jsdelivr.net/npm/@waline/client'></script>
+ <script src='//unpkg.com/@waline/client@v2/dist/waline.js'></script>
+ <link href='//unpkg.com/@waline/client@v2/dist/waline.css' rel='stylesheet' />

  <script>
-  Waline({
+  Waline.init({
    el: '#waline',
    serverURL: 'YOUR SERVER URL'
  });
  </script>
```

## Tùy chọn được bổ sung

- Tùy chọn `comment` hỗ trợ đặt chuỗi làm CSS selector.
- Tùy chọn `pageview` hỗ trợ đặt chuỗi làm CSS selector.

## Tùy chọn được đổi tên

- `uploadImage` đổi tên thành `imageUploader`

- `highlight` đổi tên thành `highlighter`

- `previewMath` đổi tên thành `texRenderer`

- `visitor` đổi tên thành `pageview`

## Tùy chọn bị loại bỏ

Các tùy chọn sau đã bị đánh dấu là API không còn dùng từ lâu trong V1 và đã bị loại bỏ trong V2.

- `langMode`: dùng `locale`
- `placeholder`: dùng `locale.placeholder`
- `emojiCDN`: dùng `emoji`
- `emojiMaps`: dùng `emoji`
- `requiredFields`: dùng `requiredMeta`
- `avatar`: dùng biến máy chủ `AVATAR_PROXY`
- `avatarCDN`: dùng biến máy chủ `AVATAR_PROXY`
- `avatarForce`: mặc định làm mới
- `anonymous`: dùng `login`
- `mathTagSupport`: dùng `texRenderer`
- `copyRight`: dùng `copyright`

## Thay đổi khác

### Instance

`Waline.init` giờ sẽ ném lỗi khi hai thuộc tính bắt buộc `el`, `serverURL` không hợp lệ, thay vì trả về một instance lỗi kèm lý do.

Bạn có thể dùng khối `try { ... } catch (err) { ... }` để bắt lỗi, giúp tương thích tốt hơn trong trường hợp người dùng đặt tùy chọn không hợp lệ.

### Thay đổi hành vi cập nhật

- Waline giờ hỗ trợ cập nhật mọi tùy chọn trừ tùy chọn `el` thông qua `Instance.update`.
- Tham số `path` sẽ được đặt lại khi gọi `update()`, nghĩa là chừng nào bạn không truyền tùy chọn `path` trong `update()` thì nó sẽ là `window.location.pathname`.

### Thay đổi selector của bình luận và lượt xem

Khả năng tương thích selector của Valine cho bình luận và lượt xem đã bị loại bỏ.

- Selector bình luận mặc định là `'.waline-comment-count'`
- Selector lượt xem mặc định là `'.waline-pageview-count'`

Nếu bạn cần lấy một giá trị khác với trang hiện tại cho một selector, rất khuyến nghị dùng thuộc tính `data-path`.

Để tương thích, chúng tôi vẫn giữ hỗ trợ thuộc tính `id` trước đây, nhưng khả năng tương thích này sẽ bị loại bỏ trong V3.

### Thay đổi lớp CSS

Toàn bộ lớp CSS đổi từ `v` sang `wl-`.
