Waline có sẵn hỗ trợ đa ngôn ngữ, và bạn cũng có thể tùy chỉnh cấu hình ngôn ngữ của Waline.

<!-- more -->

## Ứng dụng khách

### Đặt ngôn ngữ

Bạn có thể đặt ngôn ngữ mà Waline sử dụng thông qua tùy chọn `lang`. Các ngôn ngữ được hỗ trợ:

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

Ví dụ:

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Nếu bạn muốn giúp Waline hỗ trợ thêm ngôn ngữ, chúng tôi hoan nghênh bạn gửi PR tới [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n).

:::

### Tùy chỉnh

Bạn có thể tùy chỉnh ngôn ngữ thông qua tùy chọn `locale`, hoặc đặt một số trường để ghi đè văn bản giao diện hiện có.

Chi tiết xem [Sổ tay → Tùy chỉnh ngôn ngữ](../../cookbook/customize/locale.md).

## Máy chủ

Thông tin do giao diện máy chủ trả về sẽ tự động chuyển ngôn ngữ dựa trên tham số lang do ứng dụng khách gửi lên.

## Tùy chỉnh

Bạn có thể tùy chỉnh nội dung cho ngôn ngữ tương ứng bằng tùy chọn `locales`, xem [Sổ tay → Tùy chỉnh ngôn ngữ](../../cookbook/customize/locale.md) để biết chi tiết.
