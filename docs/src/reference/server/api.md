## 评论接口

### 评论列表

获取某篇文章对应的评论列表

```http
GET /api/comment
```

**参数**:

| 字段     | 类型   | 描述                                                                                                           |
| -------- | ------ | -------------------------------------------------------------------------------------------------------------- |
| path     | string | 获取对应文章标识的评论列表                                                                                     |
| page     | number | 评论列表的页数                                                                                                 |
| pageSize | number | 每页评论列表的条数                                                                                             |
| sortBy   | string | 评论排序方式，默认按时间倒序(insertedAt_desc)，还可以选择按时间正序（insertedAt_asc），按热度倒序（like_desc） |

`like_desc` 以整串討論的**主留言讚數＋公開回覆數＋公開回覆讚數**排序，包含各層回覆。待審、垃圾留言及其他頁面的回覆不計入熱度，即使目前使用者有權限看到這些留言也一樣。置頂留言仍排最前面；同分時依留言 ID 倒序排列。回傳的 `like` 仍代表該則留言本身的讚數。

熱度在查詢時、分頁前計算，既有留言及後續按讚、審核、刪除、資料匯入都不需要額外回填。SQL、MongoDB 與 CloudBase 在資料庫內完成排序；GitHub 儲存原本就會將 CSV 載入記憶體。舊版 LeanCloud 後端則讀取該頁所有留言的排序欄位，在記憶體排序後才讀取當頁留言內容，因此資源成本會隨留言數增加。

既有 SQL 資料庫建議新增 `(rid, url, status)` 索引，避免每個主留言都掃描整張表；新部署的 SQL 範本已包含索引。例如（請依部署調整資料表名稱與前綴）：

```sql
CREATE INDEX idx_comment_rid_url_status ON wl_Comment (rid, url, status);
```

MongoDB／CloudBase 請建立相同欄位順序的複合索引。

### 评论数

获取某篇文章对应的评论总数

```http
GET /api/comment?type=count
```

**参数**:

| 字段 | 类型   | 描述                                                 |
| ---- | ------ | ---------------------------------------------------- |
| url  | string | 获取对应文章标识的评论列表，如果为空会返回全站评论数 |

### 最近评论

获取当前网站的最近评论

```http
GET /api/comment?type=recent
```

**参数**:

| 字段  | 类型   | 描述               |
| ----- | ------ | ------------------ |
| count | number | 返回最新评论的条数 |

### 发布评论

发布一条评论

```http
POST /api/comment
```

**参数**:

| 字段    | 类型   | 描述                         |
| ------- | ------ | ---------------------------- |
| comment | string | 评论内容                     |
| link    | string | 用户输入的网站               |
| mail    | string | 用户输入的邮箱               |
| nick    | string | 用户输入的昵称               |
| pid     | string | 该条评论回复的评论 objectId  |
| rid     | string | 该条评论的根评论 objectId    |
| ua      | string | 用户的 user agent            |
| url     | string | 评论的文章标识               |
| at      | string | 该条评论回复的评论的作者昵称 |

## 阅读统计接口

### 获取阅读统计数

获取某篇文章或者多篇文章对应的阅读数

```http
GET /api/article
```

**参数**:

| 字段 | 类型   | 描述                               |
| ---- | ------ | ---------------------------------- |
| path | string | 对应文章标识，多个标识使用逗号拼接 |

### 更新阅读统计数

更新某篇文章的阅读数

```http
POST /api/article
```

**参数**:

| 字段 | 类型   | 描述         |
| ---- | ------ | ------------ |
| path | string | 对应文章标识 |
