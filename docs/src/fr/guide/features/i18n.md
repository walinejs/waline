Waline dispose d'une prise en charge multilingue intégrée, et vous pouvez également personnaliser la configuration de la locale de Waline.

<!-- more -->

## Client

### Définir la langue

Vous pouvez définir la langue utilisée par Waline avec l'option `lang`. Les langues prises en charge sont :

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

Par exemple :

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Si vous souhaitez aider Waline à prendre en charge davantage de langues, nous vous invitons à envoyer une PR sur [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n).

:::

### Personnaliser

Vous pouvez personnaliser la langue avec l'option `locale`, ou remplacer certains textes de l'interface en définissant les champs correspondants.

Pour plus de détails, voir [Cookbook → Personnaliser la locale](../../cookbook/customize/locale.md).

## Serveur

Les informations renvoyées par l'interface du serveur changent automatiquement de langue selon le paramètre `lang` transmis par le client.

## Personnaliser

Vous pouvez personnaliser le contenu de la langue correspondante avec l'option `locales`. Voir [Cookbook → Personnaliser la locale](../../cookbook/customize/locale.md) pour plus de détails.
