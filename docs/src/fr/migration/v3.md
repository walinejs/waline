## Changements de la plage de prise en charge

- Node.js :

  La V3 ne prend en charge que la dernière version LTS de Node.

  Les versions LTS actuelles sont Node.js 18 et Node.js 20, ce qui signifie que la prise en charge de Node 14 et Node 16 a été supprimée.

- Navigateur :

  La V3 ne prend en charge que les navigateurs modernes, conformément à la [plage de navigateurs par défaut](https://vitejs.dev/guide/build.html#browser-compatibility) de Vite
  - Chrome >=87
  - Firefox >=78
  - Safari >=14
  - Edge >=88

## Suppression de fonctionnalités

- Désormais, lors de la récupération du chemin associé à un élément de compteur, `id` n'est plus lu. Vous devez utiliser `data-path`.
- Les paquets hérités ont été supprimés.

## Mise à jour des variables CSS

La variable `bgcolor` des variables CSS devient `bg-color` :

```diff
---waline-bgcolor: #fff;
+--waline-bg-color: #fff;
---waline-bgcolor-light: #f8f8f8;
+--waline-bg-color-light: #f8f8f8;
---waline-bgcolor-hover: #f0f0f0;
+--waline-bg-color-hover: #f0f0f0;
---waline-disable-bgcolor: #f8f8f8;
+--waline-disable-bg-color: #f8f8f8;
---waline-code-bgcolor: #282c34;
+--waline-code-bg-color: #282c34;
---waline-info-bgcolor: #f8f8f8;
+--waline-info-bg-color: #f8f8f8;
```
