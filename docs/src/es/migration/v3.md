## Cambios en el rango de soporte

- Node.js:

  V3 solo admite la última versión LTS de Node.

  Las versiones LTS actuales son Node.js 18 y Node.js 20, lo que significa que hemos eliminado el soporte para Node.14 y Node 16.

- Navegador:

  V3 solo admite navegadores modernos, en línea con el [rango de navegadores compatibles por defecto](https://vitejs.dev/guide/build.html#browser-compatibility) de Vite
  - Chrome >=87
  - Firefox >=78
  - Safari >=14
  - Edge >=88

## Funciones eliminadas

- Ahora, al obtener la ruta vinculada a un elemento contador, ya no se lee `id`. Debes usar `data-path`.
- Se han eliminado los paquetes heredados.

## Actualización de las variables CSS

La variable `bgcolor` de las variables CSS cambia a `bg-color`:

```diff
---waline-bgcolor: #fff;
+--waline-bg-color: #fff;
---waline-bgcolor-light: #f8f8f8;
+--waline-bg-color-light: #f8f8f8;
---waline-bgcolor-hover: #f0f0f0;
+--waline-bg-color-hover: #f0f0f0;
---waline-disable-bgcolor: #f8f8f8;
+--waline-disable-bg-color: #f8f8f8;
---waline-code-bgcolor: #282c34;
+--waline-code-bg-color: #282c34;
---waline-info-bgcolor: #f8f8f8;
+--waline-info-bg-color: #f8f8f8;
```
