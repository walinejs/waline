Waline incluye soporte multilenguaje y también puedes personalizar la configuración de idioma de Waline.

<!-- more -->

## Cliente

### Establecer el idioma

Puedes establecer el idioma que usa Waline mediante la opción `lang`. Los idiomas admitidos son:

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

Por ejemplo:

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Si quieres ayudar a Waline a admitir más idiomas, te damos la bienvenida a enviar un PR a [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n).

:::

### Personalizar

Puedes personalizar el idioma mediante la opción `locale`, o establecer algunos campos para sobrescribir los textos de la interfaz existentes.

Para más detalles, consulta [Recetario → Personalizar el idioma](../../cookbook/customize/locale.md).

## Servidor

La información que devuelve la interfaz del servidor cambiará de idioma dinámicamente según el parámetro lang que envíe el cliente.

## Personalizar

Puedes personalizar el contenido del idioma correspondiente con la opción `locales`; consulta [Recetario → Personalizar el idioma](../../cookbook/customize/locale.md) para más detalles.
