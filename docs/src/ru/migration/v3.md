## Изменения поддерживаемых версий

- Node.js:

  V3 поддерживает только последнюю LTS-версию Node.

  Сейчас это Node.js 18 и Node.js 20, то есть поддержка Node.js 14 и Node.js 16 удалена.

- Браузеры:

  V3 поддерживает только современные браузеры в соответствии с [диапазоном браузеров по умолчанию](https://vitejs.dev/guide/build.html#browser-compatibility) в Vite
  - Chrome >=87
  - Firefox >=78
  - Safari >=14
  - Edge >=88

## Удалённые возможности

- Теперь при получении пути, привязанного к элементу счётчика, атрибут `id` больше не читается. Следует использовать `data-path`.
- Устаревшие пакеты удалены.

## Обновление CSS-переменных

CSS-переменная `bgcolor` изменена на `bg-color`:

```diff
---waline-bgcolor: #fff;
+--waline-bg-color: #fff;
---waline-bgcolor-light: #f8f8f8;
+--waline-bg-color-light: #f8f8f8;
---waline-bgcolor-hover: #f0f0f0;
+--waline-bg-color-hover: #f0f0f0;
---waline-disable-bgcolor: #f8f8f8;
+--waline-disable-bg-color: #f8f8f8;
---waline-code-bgcolor: #282c34;
+--waline-code-bg-color: #282c34;
---waline-info-bgcolor: #f8f8f8;
+--waline-info-bg-color: #f8f8f8;
```
