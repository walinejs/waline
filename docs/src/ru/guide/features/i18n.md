Waline имеет встроенную поддержку нескольких языков, а также позволяет настраивать конфигурацию локалей.

<!-- more -->

## Клиент

### Установка языка

Вы можете задать используемый Waline язык с помощью параметра `lang`. Поддерживаются следующие языки:

- zh
- zh-CN
- zh-TW
- en
- en-US
- de
- es
- es-MX
- fr
- fr-FR
- id
- id-ID
- it
- it-IT
- jp
- jp-JP
- ko
- ko-KR
- pt-BR
- ru
- ru-RU
- vi
- vi-VN

Например:

```js
Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});
```

::: tip

Если вы хотите помочь Waline добавить поддержку новых языков, мы будем рады вашему PR в [client/config/i18n](https://github.com/walinejs/waline/tree/main/packages/client/src/config/i18n).

:::

### Настройка

Вы можете настроить язык с помощью параметра `locale` или переопределить отдельные поля существующего текста интерфейса.

Подробнее см. [Рецепты → Настройка локали](../../cookbook/customize/locale.md).

## Сервер

Информация, возвращаемая интерфейсом сервера, динамически переключает язык в зависимости от параметра lang, переданного клиентом.

## Настройка

Вы можете настроить содержимое для соответствующего языка с помощью параметра `locales`, подробнее см. [Рецепты → Настройка локали](../../cookbook/customize/locale.md).
