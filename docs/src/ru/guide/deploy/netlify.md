[Netlify](https://netlify.com) — известный провайдер услуг по развёртыванию статических сайтов, а [Edge Functions](https://www.netlify.com/blog/edge-functions-explained/) — платформа, запущенная Netlify, которая позволяет выполнять JavaScript-код на граничных узлах сайтов.

<!-- more -->

## Как развернуть

Нажмите кнопку [Fork](https://github.com/walinejs/netlify-starter/fork), чтобы создать стартовый шаблон Netlify.

![netlify](../../../assets/netlify-1.png)

Войдите в консоль Netlify по адресу <https://app.netlify.com> и выберите <kbd>Add new site</kbd> - <kbd>Import an exist project</kbd>, чтобы добавить сайт. Выберите авторизацию через GitHub, чтобы прочитать список ваших GitHub-проектов. Найдите в списке имя репозитория, созданного только что при форке, и нажмите на проект, чтобы начать создание сайта Netlify на основе этого репозитория.

![netlify](../../../assets/netlify-2.png) ![netlify](../../../assets/netlify-3.png)

Перед созданием сайта Netlify нужно заполнить часть конфигурации. Помимо переменных окружения, остальные параметры можно оставить по умолчанию. Добавьте переменные окружения соответствующего хранилища, как описано в разделе [Поддержка нескольких баз данных](../database.md), затем нажмите <kbd>Deploy site</kbd> внизу, чтобы начать развёртывание сайта.

![netlify](../../../assets/netlify-4.png)

Через некоторое время сайт Netlify будет успешно развёрнут. Нажмите <kbd>Functions</kbd> в верхней панели навигации, чтобы перейти к списку облачных функций: `comment` — это развёрнутый сервис Waline. Нажмите на него, чтобы открыть страницу сведений о функции.

![netlify](../../../assets/netlify-5.png)

На странице сведений адрес, указанный в `Endpoint`, — это адрес развёрнутого сервиса Waline. Нажмите кнопку копирования справа, откройте адрес в новой вкладке и проверьте отправку комментария: если всё прошло успешно, настройте этот домен в клиенте и комментируйте с удовольствием!

![netlify](../../../assets/netlify-6.png) ![netlify](../../../assets/netlify-8.png)

## Как обновить

Перейдите в репозиторий GitHub и измените номер версии `@waline/vercel` в файле package.json на последнюю версию.

## Как изменить переменные окружения

Нажмите `Site settings` в верхней панели навигации, выберите боковую панель `Environments variables` и перейдите на страницу управления переменными окружения. Нажмите кнопку `Add a variable`, чтобы добавить переменную окружения.

После редактирования переменных окружения нужно перейти на страницу `Deploys`, выбрать `Trigger deploy` - `Deploy site` и развернуть сайт заново, чтобы переменные окружения вступили в силу.

![netlify](../../../assets/netlify-9.png) ![netlify](../../../assets/netlify-10.png)
