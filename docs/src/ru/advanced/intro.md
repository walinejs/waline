::: info Waline

Простая система комментариев с поддержкой серверной части, форк [Valine](https://valine.js.org).

:::

<!-- more -->

## Возможности

- Быстрая
- **Действительно** безопасная
- Поддержка полного синтаксиса Markdown
- Простая и лёгкая
- Бесплатное развёртывание!
- Поддержка множества сервисов развёртывания и хранения — не менее 243 вариантов развёртывания!

|                                                 | Waline                                                              |                                    |
| ----------------------------------------------- | ------------------------------------------------------------------- | ---------------------------------- |
| **Клиент**                                      | **Сервер**                                                          | **База данных**                    |
